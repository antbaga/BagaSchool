## Cycle 2 — histoire
- CP : jour/nuit, saisons ; année (12 mois), semaine (7 jours), journée (24 h) ; événements de la classe.
- CE1 thème 1 : années, décennies, siècles, millénaires.
- CE1 thème 2 « Les grandes périodes de l'histoire » (une ou deux figures par période) :
  Préhistoire (environ 3 millions d'années à 3000 av. J.-C.) ; Antiquité (environ 3000 av. J.-C. à 476 ap. J.-C.) ;
  Moyen Âge (476 à 1492) ; Temps modernes (1492 à 1789) ; époque contemporaine (1789 à nos jours).
- CE1 thème 3 : traces du passé (fossiles, ossements, grottes, ruines, monuments, objets, écrits, images, œuvres d'art, témoignages).
- CE2 thème 1 Paléolithique/Néolithique : vers 10000/9000 av. J.-C. naissance de l'agriculture ; 3200 av. J.-C. Ötzi ;
  vers 3000 av. J.-C. apparition de l'écriture ; un site préhistorique en France ; peinture pariétale, premiers métaux.
- CE2 thème 2 Rome et Gaule romaine : 52 av. J.-C. siège d'Alésia, défaite de Vercingétorix ; 27 av. J.-C.–14 ap. J.-C. règne d'Auguste ;
  étendue de l'empire romain à son apogée ; un site gallo-romain.
- CE2 thème 3 Construction du royaume de France (Xe–XVe s.) : 987 élection d'Hugues Capet ; XIVe–XVe s. guerre de Cent Ans ;
  Capétiens, Valois ; Philippe Auguste ; Aliénor d'Aquitaine ; Blanche de Castille ; le sacre.

## Cycle 2 — géographie
- CP : plan de la classe, quartier, trajet ; continents ; océans Atlantique, Pacifique, Indien ; la France ; grands foyers de peuplement ; points cardinaux.
- CE1 : une ville très peuplée par continent ; zones climatiques (tropicale, tempérée, froide) ; forêts (amazonienne, bassin du Congo, indonésienne) ;
  déserts (Antarctique, Sahara) ; fleuves « Amazone, Mississippi, Nil » ; massifs « Andes, Alpes, Atlas, Himalaya, Rocheuses » ; montagne, plaine, plateau, vallée.
- CE2 : cinq premières agglomérations françaises ; massifs : Alpes, Corse, Jura, Massif Central, Pyrénées, Vosges, un massif ultramarin ;
  fleuves : Garonne, Loire, Maroni, Rhin, Rhône, Seine ; paysages résidentiels et de travail.

## Cycle 3 — histoire
- CM1 thème 1 Vie quotidienne au Moyen Âge (XIe–XIIIe) : Moyen Âge 476–1492 sur une frise ; abbaye de Cluny ; Notre-Dame de Paris ; art roman / gothique.
- CM1 thème 2 Monarchie (XVIe–XVIIe) : 1515 début du séjour de Léonard de Vinci en France (mort en 1519) ; 1598 édit de Nantes ;
  1643–1715 règne de Louis XIV ; François Ier (1515–1547), Henri IV (1589–1610) ; trois ordres ; Versailles.
- CM1 thème 3 Explorations : 1492 Christophe Colomb en Amérique ; 1519–1522 expédition de Magellan ; 1685 « Code noir » ; empires coloniaux ;
  tomate, chocolat, haricot, pomme de terre, sucre de canne.
- CM1 thème 4 1789 : printemps 1789 cahiers de doléances, États généraux ; 14 juillet prise de la Bastille ; nuit du 4 août abolition des privilèges ;
  26 août DDHC ; 5–6 octobre marche des femmes sur Versailles ; un ou une philosophe des Lumières.
- CM2 thème 1 République et Empire : mars 1792 pétition de 319 femmes (Pauline Léon) ; avril 1792 La Marseillaise ; septembre 1792 naissance de la République ;
  1794 première abolition de l'esclavage ; 1802 rétablissement ; 2 décembre 1804 sacre de Napoléon Ier ; Code civil, lycées.
- CM2 thème 2 IIe et IIIe République : 1848 suffrage universel masculin et abolition définitive de l'esclavage ; 1882–1886 lois Ferry ;
  9 décembre 1905 séparation des Églises et de l'État ; symboles (drapeau, 14 juillet, Marianne, Marseillaise, devise).
- CM2 thème 3 Âge industriel : début XIXe locomotive (Stephenson) ; fin XIXe vaccin contre la rage (Pasteur) ; droit de grève, liberté syndicale.
- CM2 thème 4 : 1914–1918 Première Guerre mondiale ; 11 novembre 1918 armistice.
- CM2 thème 5 : 1939–1945 ; 18 juin 1940 appel du général de Gaulle ; 1942 rafle du Vel d'Hiv ; 6 juin 1944 débarquement en Normandie ;
  8 mai 1945 capitulation de l'Allemagne nazie ; de Gaulle, Jean Moulin, Justes parmi les Nations.
- CM2 thème 6 : 1944 droit de vote des femmes ; 1957 traité de Rome (CEE) ; 1958 Ve République ; 1965 les femmes peuvent travailler
  sans l'autorisation de leur époux et ouvrir un compte ; 2000 l'euro remplace le franc (pièces et billets en 2002).
- 6e : feu vers 400000 av. J.-C. ; Homo sapiens vers 300000 av. J.-C. (Maroc) ; roue vers 4000 av. J.-C. ; écriture cunéiforme vers 3000 av. J.-C. ;
  Périclès Ve s. av. J.-C. ; Alexandre le Grand 336–323 av. J.-C. ; [résumé] Massalia vers 600 av. J.-C., Vix, Bibracte.

## Cycle 3 — géographie
- CM1 « diversité des modes de vie dans le monde » : se nourrir, inégalités, se déplacer, communiquer (régions du monde : Afrique subsaharienne, Maghreb, … [résumé]).
- CM2 « la France, l'Union européenne » [résumé] : 5 plus grandes agglomérations, axes, les 18 régions et leurs capitales, le département de l'élève ;
  fleuves Garonne, Loire, Maroni, Rhin, Rhône, Seine ; massifs Alpes, Corse, Jura, Massif central, Pyrénées, Vosges ; deux grands lacs ;
  UE : 1957, 1992 (Maastricht), dix États membres dont les six fondateurs.
- 6e : équateur, tropiques, cercles polaires, Greenwich ; déserts Atacama, Gobi, Sahara ; Amazonie, Congo, Indonésie ; Alpes, Andes, Atlas, Himalaya, Rocheuses.

- CM1 : art roman, art gothique, cathédrale, abbaye, Cluny, Notre-Dame ; Léonard de Vinci et François Ier.
- 6e : Lascaux, Chauvet ; Babylone, Abou Simbel, Ramsès II ; Acropole, Olympie, théâtre.
